### What I'm building

**[Somos Nexo](https://www.somosnexo.app)** — AI-powered two-sided talent marketplace · *Nov 2025 – present, Alpha released Jun 2026*
Founder and lead engineer. Next.js (App Router, RSC), TypeScript, PostgreSQL, Tailwind, Stripe.
An **LLM evaluation pipeline** ingests a candidate's GitHub repository and returns line-by-line code review scored on architecture, best practices and requirements — replacing manual technical screening. Also built: credit-metered AI billing with Stripe Checkout, webhooks and multi-currency across B2C and B2B plans; GitHub OAuth with automated analysis triggers; recruiter-side skill search with candidate-to-job matching and applicant tracking; an AI roleplay module for soft-skill assessment; server-side PDF portfolio generation; full pt-BR/en internationalization.

**Pleione** — SaaS ERP for environmental compliance · *Jan 2026 – present*
Sole engineer on a six-module platform for environmental consultancies: CRM, sales pipeline, licensing and document workflows, deadline calendar, projects/kanban with time tracking, and accounts payable/receivable. The core problem is regulatory: a missed license deadline carries legal and financial exposure, so the system consolidates obligations across licenses, conditions and contracts into a single authoritative calendar.

**VendON** — multi-tenant SaaS ERP for order management
Next.js, React, Supabase (PostgreSQL, auth, Edge Functions), Redis caching, Mercado Pago subscription billing with webhook-driven state, and a RESTful API documented to the OpenAPI spec.

> Nexo and Pleione are private (commercial products). Happy to walk through architecture and code in a conversation.
